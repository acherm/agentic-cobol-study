## How to build/run (from the project's own README)

```bash
cobc -x -O -o cobolcc  cobolcc.cob     # compiler (requires GnuCOBOL 3.x)
cobc -x -O -o cobolint cobolint.cob    # interpreter
./cobolcc tests/test1-hello.cob        # → tests/test1-hello.c
gcc -O2 -lm -o hello tests/test1-hello.c && ./hello
./cobolint tests/test1-hello.cob       # or interpret directly
./benchmark.sh                          # GnuCOBOL vs cobolcc benchmark
```

Build-flag caveat discovered in session de76ffeb: on macOS ARM64 with Homebrew GNU Binutils on PATH, `cobc -x -O2` hangs because GnuCOBOL's post-link `strip -x` resolves to GNU `strip` which corrupts Mach-O. Workaround: `brew unlink binutils` or `PATH=/usr/bin:$PATH cobc -x -O2 …`. See SB-032 in `SPECIFICATION_BACKLOG.md`.
